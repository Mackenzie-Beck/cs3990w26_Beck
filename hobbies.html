    Hobbies

    Game Development

    Here are a collection of some hobby projects that I have worked on.

    MathWiz

    MathWiz is a prototype top-down 2D RPG which teaches basic math skills like multiplication.
    Explore the village, talk to its inhabitants, and see if you can beat the two dungeons to earn the title of MathWiz!
    This project took me just about a year of on-and-off work to complete. While I've lost interest in this game specifically I still learned a lot and built a lot of useful systems. I definitely want to revisit the idea of a 2D-rpg math trainer in the future.

    I continued this kind of educational game development with my student research work at Northwestern Polytechnic

    FarmerAbduction

    This project was an attempt to finish a game in one month. It lacks a lot of polish and has not had any play testing. I mostly keep it around for the nostalgia and as a milestone for how far i've come.

    Both of the above projects can be found on my itch.io page here.


    Student Research Project at NWP

    This project is another educational game that is currently under development. While working as a student research assistant at NWP I have been developing this math trainer meant to teach children around grades 9-10 about linear transformations on the graph.
    It is expected to be released fully by the end of March.

    Bachelors of Computer Science Capstone Project

    A project which I am starting this semester is my capstone. Which will be another educational game. However one thing we want to focus on is encouraging face to face interaction between students, as excessive screen time has been show to have negative effects on students social skills. We also want to incorporate cooperative elements as this has been shown to assist in a positive classroom environment. For my own part, I really value the focus on cooperative mechanics, as I think it is important to encourage young children to cooperate.
